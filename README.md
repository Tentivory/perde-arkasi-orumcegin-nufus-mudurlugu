# Perde Arkasi Orumcegin Nufus Mudurlugu

> **Resmi Uyari:** Bu depo, evinizdeki perdenin arkasinda yillardir kayitsiz yasayan orumcegin vatandaslik basvurusunu isleme almak uzere kurulmus ulusal bir protokoldur. Temizlik personeli bu yazilimi baslatmadan once orumcege tebligat birakmalidir.

## Bu nedir?

Bilim. Burokrasi. Sekiz ayak. Ucunu birlestirince ortaya **calisan** bir Python programi cikar.

Program:

1. Orumcege kimlik numarasi uretir (26 ile baslar, cunku Eskisehir).
2. Vergi numarasi basar.
3. Yillik ag vergisini hesaplar.
4. Perdeye asilabilecek ciddiyetde bir kimlik belgesi basar.
5. Hicbir sorunu cozmez.

## Kurulum

```bash
python3 nufus_mudurlugu.py
```

Python 3 yeterlidir. Baska hicbir sey gerekmez. Orumcek dahil.

## Neden var?

Cunku perde arkasindaki canlilar da kayit altina alinmak ister. Kayitsiz orumcek, kayitsiz toz biriktirir. Kayitsiz toz, kayitsiz hapşırık dogurur. Kayitsiz hapşırık ise kutuphane yonetmeligini ihlal eder. Zincir boyle uzar.

## Siklikla sorulan sorular

**Orumcek imza atabilir mi?**  
Hayir. Ayak izi yeterlidir. Sekiz kopya.

**Temizlik yaparsam vatandaslik duser mi?**  
Duser. Ayrica mudurluk size nota gonderir.

**Patates var mi?**  
Yok.

**Bu yasal mi?**  
Mudurluk icinde evet. Mudurluk disinda hayir. Mudurluk perde arkasindadir.
